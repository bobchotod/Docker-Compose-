# 🛒 Онлайн Магазин — Docker Compose проект

PHP/MySQL уеб приложение, контейнеризирано с Docker Compose. Включва потребителска регистрация/вход, продуктов каталог и администраторски панел.

---

## 📁 Структура на проекта

```
project/
├── Dockerfile              # Конфигурация на PHP/Apache контейнера
├── compose.yml             # Docker Compose дефиниция на услугите
├── web/
│   └── index.php           # Целият PHP сорс код на приложението
└── db/
    └── init.sql            # SQL скрипт за инициализация на базата данни
```

---

## 🧩 Компоненти / Услуги

### 1. `web` — PHP + Apache уеб сървър
- Базиран на официалния образ `php:8.2-apache`
- Изгражда се от локалния `Dockerfile`
- Работи на порт **8080** (пренасочен от вътрешен порт 80)
- Съдържа цялото PHP приложение в `/var/www/html/`
- Инсталирани PHP разширения: `pdo`, `pdo_mysql`
- Активиран Apache модул `mod_rewrite`

### 2. `db` — MySQL 8.0 база данни
- Използва официалния образ `mysql:8.0` (без собствен Dockerfile)
- Работи на порт **3306**
- При първо стартиране автоматично изпълнява `init.sql`
- Данните се пазят в Docker том `db_data` (персистентни)

---

## 🗄️ База данни

Файлът `db/init.sql` създава базата `web_project` с две таблици:

| Таблица | Описание |
|---------|----------|
| `users` | Потребители — потребителско име, имейл, хеширана парола, профилна снимка |
| `products` | Продукти — name, description, price |

---

## 🔗 Комуникация между услугите

Docker Compose поставя двата контейнера в обща вътрешна мрежа. PHP приложението се свързва към MySQL, като използва **името на контейнера** като хост:

```php
$host = 'db'; // вместо 'localhost'
$db   = 'web_project';
$user = 'root';
$pass = 'secret123';
$pdo  = new PDO("mysql:host=$host;dbname=$db;charset=utf8mb4", $user, $pass);
```

Услугата `web` зависи от `db` (`depends_on`), за да се стартира след нея.

## 🚀 Изграждане и стартиране

### Изисквания
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (или Docker Engine + Docker Compose v2)

### Стъпки

```bash
# 1. Клонирайте хранилището
git clone https://github.com/<вашият-потребител>/<вашето-repo>.git
cd <вашето-repo>

# 2. Изградете и стартирайте контейнерите
docker compose up -d --build

# 3. Отворете приложението в браузъра
# http://localhost:8080
```

### Спиране на контейнерите

```bash
docker compose down
```

### Пълно изчистване (включително данни от базата)

```bash
docker compose down -v
```

## 👤 Вход в приложението

| Роля | Потребителско име | Описание |
|------|-------------------|----------|
| Администратор | `admin` | Достъп до панела за управление на продукти |
| Потребител | (регистриран) | Разглеждане на каталога и профил |

> **Забележка:** Акаунтът `admin` трябва да бъде регистриран ръчно от страницата за регистрация или добавен директно в базата данни.
